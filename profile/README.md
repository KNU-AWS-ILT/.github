# 🏗️ ArchiMate, "나의 첫 간편 클라우드 서비스"

> 혼자서도 관리할 수 있는 서비스로 바꿔 주는 AI 클라우드 설계 플랫폼입니다!

## 📖 프로젝트 소개

바이브 코딩으로 서비스는 만들었지만,<br/>
서버 비용과 유지보수가 막막한 당신!
<br/>

**ArchiMate**는 몇 가지 질문만으로 팀 예산과 역량에 맞는 클라우드 서비스를 구성해 드립니다!
<br/>

나의 첫 서비스를 간편하게, 그리고 오랫동안 운영할 수 있도록<br/>
클라우드 서비스 구성도, 월 예상 비용, 배포·운영 절차를 한 번에!

---

## 🎯 문제 정의

바이브 코딩으로 서비스는 빠르게 만들 수 있지만,<br/>
배포·운영 단계에서 여전히 클라우드 지식이 필요!🫠
<br/>

우리 팀만의 예산에 맞게 역산해 주는 도구가 없어<br/>
먼저 클라우드 서비스를 설계해야 하고,<br/>
서비스 중 예상 밖의 청구서가 발생하는 상황!💀
<br/>

기존 서비스는 "무엇을 만들지 이미 아는 사람"을 전제로 운영하고 있었습니다.
<br/>

그래서 **ArchiMate**는 클라우드 서비스가 처음인 사용자도<br/>
몇 가지 질문만으로 클라우드 진입 장벽을 낮춥니다!
